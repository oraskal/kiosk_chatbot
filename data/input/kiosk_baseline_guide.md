# 의사랑 키오스크 설치가이드 재구성본 (기본 설정 기준)

- 원본 문서: **의사랑 키오스크 설치가이드_대리점용 Version 1.9 / Update 2024.11.29**
- 목적: 키오스크 챗봇이 **기본 설치 세팅(Baseline)** 을 우선 참조할 수 있도록, 원본 PDF를 RAG 친화적인 마크다운 문서로 재구성
- 적용 범위: 풀 키오스크(점자 미부착/점자 부착), 하프 키오스크
- 주의: 아래 내용은 **기본 설치/운영 기준** 이며, 실제 현장 커스터마이징이 있다면 챗봇 답변에서 반드시 “기본 설정 대비 이탈 여부”를 같이 확인해야 한다.

---

## 1. 문서의 용도와 읽는 방법

이 문서는 키오스크 장애 대응 시 다음 순서의 답변 흐름에서 **‘우선 확인사항’과 ‘권장 대응 방향’의 기준값** 으로 쓰기 위한 문서다.

1. 의심되는 원인
2. 우선 확인사항
3. 권장 대응 방향
4. 병원 안내용 답변 초안
5. 가장 유사한 사례 요약
6. 유사 사례 참고

특히 2~3번에서 중요한 것은, 단순히 과거 지원 이력을 찾는 것이 아니라 **현재 현장이 배포 당시 기본 세팅에서 벗어났는지** 를 먼저 보는 것이다.

## 2. 제품 구성 요약

### 2.1 풀 키오스크 (점자 미부착)

- 외관 크기: `430(W) x 1650(H) x 495(D) mm`
- 구성 요소
  - 처방전 프린터
  - 후면 도어
  - 영수증 롤프린터
  - 전원 버튼
  - USB 포트
  - 전원 플러그
  - 전원 스위치
  - LAN 포트
  - 바퀴
- 처방전 프린터 기본 모델
  - 삼성 `SL-M3830ND`
  - 레이저 프린터 / 흑백
  - 급지대 2단, 총 770매
    - 1단 250매
    - 2단 520매
  - 토너
    - `MLT-D403S / TND` : 약 3,000매
    - `MLT-D405L / TND` : 약 5,000매
- 영수증 롤프린터
  - 카드 / 삼성페이 영수증 출력
  - `3 inch roll`
  - 사이즈 `79 x 80 mm`
- 바퀴
  - 고정: 빨간색 고정장치를 왼쪽으로 감기
  - 해제: 고정장치를 오른쪽으로 감기

### 2.2 풀 키오스크 (점자 부착)

- 외관 크기: `430(W) x 1650(H) x 495(D) mm`
- 점자 키패드 크기: `122(W) x 66(H) x 15.3(D) mm`
- 나머지 프린터/롤프린터 사양은 점자 미부착 풀 키오스크와 동일

### 2.3 하프 키오스크

- 외관 크기: `385(W) x 879(H) x 300(D) mm`
- 점자 키패드 크기: `122(W) x 66(H) x 15.3(D) mm`
- 구성 요소
  - 바코드 리더기
  - 점자 키패드
  - 카드/페이 결제부
  - 전원 플러그
  - 전원 스위치
  - USB 포트
  - LAN 포트
  - 영수증 롤프린터
- 영수증 롤프린터
  - 카드 / 삼성페이 / 애플페이 영수증 출력
  - `3 inch roll`
  - 사이즈 `79 x 80 mm`

## 3. 설치 전체 순서 (Baseline Workflow)

### 3.1 선행 조건

- 키오스크 기기가 설치되어 있고 전원이 들어와 있어야 함
- 최신 버전의 의사랑이 설치되어 있어야 함
- 의사랑 서버 세팅과 수진자 조회 세팅이 완료되어 있어야 함
- 프린터 장비 및 제어판 네트워크 설정이 올바르게 되어 있어야 함

### 3.2 설치 순서

1. **의사랑 최신 버전 설치**
2. **의사랑 서버 / 수진자자격조회 세팅 완료**
3. **키오스크 프로그램 설치**
4. **키오스크 HW설정 프로그램에서 기기 종류, VAN, 종료 옵션 등 기본 설정**
5. **관리자 모드에서 키오스크 메인화면 선택**
6. **의사랑 익스프레스/도구모음에서 `키오스크` 메뉴를 꺼내 사용 가능하게 구성**
7. **`키오스크 관리` 프로그램에서 `서비스 사용` ON**
8. **상세 옵션(접수, 수납, 진료실, 공지, 장애인 메뉴 등) 설정**

## 5. 의사랑 기본 세팅

## 5.1 서버 연결 설정

설치 위치: **키오스크 기기**

- 의사랑 설치 폴더 `YSR2000` 내 `의사랑 데이터베이스 설정` 툴 실행
- 설정 항목
  - 의사랑 DB 서버 PC의 IP
  - DB 서버명

### 챗봇용 체크 포인트

- 키오스크가 의사랑 서버를 못 찾는 증상
- 접수/수납 조회 자체가 안 되는 증상
- 서버명/IP 오기입, 서버 변경 후 미반영

## 5.2 수진자자격조회 설정

경로: `외래접수실 > 환경설정 > 자격조회설정`

필수 설정

- `인터넷 통신을 통한 의료급여 자격 조회 및 승인(자동)` 체크
- 인증서 설정에 **요양기관ID** 입력

### 챗봇용 체크 포인트

- 자격조회 자동 처리가 안 됨
- 인증 관련 오류
- 요양기관ID 누락 또는 인증서 연동 누락

## 5.3 요양기관정보 등록

경로: `의사랑 환경설정 > pc정보 > 기본정보`

- 요양기관정보를 빠짐없이 등록해야 함

## 5.4 업데이트 환경 체크

설치 위치: **키오스크 기기**

1. `C:\Program Files (x86)\UBcare\LiveService` 에서 `lagentmon.ini` 확인
2. 내용 중 아래 항목 확인
   - 잘못된 값: `CommandLine=lagent.ex`
   - 올바른 값: `CommandLine=lagnet.exe server`
3. 서비스에서 `Liver Service Agent Moniter` 중지 후 다시 시작

### 챗봇용 체크 포인트

- 자동 업데이트 미동작
- 업데이트 반복 실패
- 라이브 업데이트 환경 불량

## 7. 결제 에이전트 기본 상태

## 7.1 풀 키오스크 - KSNET

설치 위치: **풀 키오스크 기기**

### 정상 상태

- 작업표시줄에 KSNET 결제 에이전트 아이콘 표시
- `C:\KSAGENT\KSCAT.exe` 정상 실행
- 아이콘이 **초록색** 이면 정상

### 비정상 상태

- 아이콘이 **빨간색** 이면 비정상
- 상세 설정 화면 열어서 아래 항목 확인
  - 암호화 리더기 포트
    - 빈 값이면 `자동검색`
  - VAN 서버 주소
    - `210.181.28.137`
- `서비스 시작` 후 초록색 아이콘 복구 확인

### 챗봇용 기본 판단

- 결제 자체가 안 됨
- 단말기 연동 실패
- 포트 미설정 / 서버주소 오기입 / 에이전트 미기동 여부 우선 점검

## 7.2 하프 키오스크 - VCAT/SMARTRO

설치 위치: **하프 키오스크 기기**

VCAT 라이선스 인증 후 `통합옵션설정` 창에서 아래 항목 확인

### 자동설정

- `자동설정` 실행하여 하드웨어 자동 검색
- `서명패드 사용여부` : **미체크**

### 옵션설정 기본값

- 팝업화면 개선 로직적용: **체크**
- VCAT 팝업화면 처리 방법: **기본 선택**
- `VCAT진행단계 VCAT UI로 표시하기` : **체크해제**
- `LOG 기록 남기기` : **체크**
- `부가세 자동계산` : **체크**
- 승인방식: **연동거래**
- `화면숨김` : **체크**
- 부팅설정: **부팅 시 VCAT 자동 시작 등록 클릭**
- 서명패드 설정: **화면터치형 선택**

### 저장 전 추가 작업

- `무결성체크`
- `워킹키수신`
- `저장`

### 챗봇용 기본 판단

- 하프 키오스크 결제창 이상
- 서명패드/결제 UI 비정상
- 승인 흐름 비정상
- 자동실행 누락 / 옵션값 이탈 여부 확인

## 8. 키오스크 HW설정 Baseline

## 8.1 환경설정

### 8.1.1 기기 종류 선택

- `풀 키오스크 #점자 미부착 스탠드`
- `풀 키오스크 #점자 부착 스탠드`
- `하프 키오스크`

### 8.1.2 결제사 선택

- 풀 키오스크: **KSNET**
- 하프 키오스크: **SMARTRO**
- 테스트 결제: **테스트**

> 반드시 **기기 종류에 맞는 VAN** 을 선택해야 함.

### 8.1.3 CATID 확인

- 본사 제공 단말기 번호가 정확히 입력되어 있어야 함

### 8.1.4 종료시간 설정

- 요일별 종료시간 설정 가능
- `ON`: 해당 요일/시간에 종료
- `OFF`: 종료하지 않음
- 주의: **자동으로 켜지지는 않음. 종료만 가능하며 전원은 직접 켜야 함**

### 8.1.5 종료 / 재실행

- `키오스크 종료`: 즉시 전원 종료
- `키오스크 재실행`: 전원 껐다가 다시 켬

### 챗봇용 기본 판단

- 기기 종류와 VAN 조합이 맞는지
- CATID가 올바른지
- 종료시간 때문에 운영 중 다운된 것인지

## 9. 프린터 설정 Baseline

## 9.1 메뉴 개요

`키오스크 HW설정 > 프린터 설정`

- 매뉴얼(설치가이드 PDF 확인)
- 프린터 출력 테스트
- 프린터 점검 툴

## 9.2 프린터 유형 선택

- `일반프린터`
- `지정프린터(용지함1개)`
- `지정프린터(용지함2개)`

### 기본 기준

- 지정 프린터 기준 모델: **삼성 SL-M3830ND**
- **풀 키오스크는 `지정프린터(용지함2개)` 선택이 기본**

## 9.3 처방전 프린터 설정

- 인쇄 가능한 프린터 목록 중 선택
- 양식지 사용 여부
  - `A4`
  - `양식지`
- 지정프린터인 경우 용지함 선택 가능

## 9.4 제증명 프린터 설정

- 환자 제출용 문서 출력 프린터 지정
- 문서 예시
  - 진료비 영수증
  - 환자 보관용 처방전
  - 진료비 세부내역서

## 9.5 카드 영수증 프린터 설정

- 실물카드 / 삼성페이 / 애플페이 영수증 출력 롤프린터 지정

## 9.6 출력문구 설정

설정 가능 항목

- **문서 출력 중 안내문구**
- **문서 출력 완료 시 안내문구**

입력 제한

- 한 줄 최대 20자
- 전체 최대 60자

### 챗봇용 기본 판단

- 문서는 나오는데 안내 멘트가 이상한 경우
- 처방전/보험문서가 다른 프린터로 나가는 경우
- 풀 키오스크인데 `일반프린터` 또는 `지정프린터(용지함1개)` 로 잘못 설정된 경우

## 10. 수동 업데이트 및 테스트 설정

## 10.1 수동 업데이트

- 자동 업데이트가 안 될 때만 사용
- 실행 시
  1. 프로그램/기기 종료
  2. 업데이트 파일 자동 다운로드
  3. 업데이트 실행
  4. 자동 재실행 후 성공/실패 메시지 확인

## 10.2 테스트 설정

개발자 비밀번호 필요

- 기본 비밀번호: `ububcare`

설정 가능 항목

- 화면모드
- 자동종료
- 시연모드
- VAN 설정

### 중요 복구 기준

테스트 종료 후 반드시 다음으로 원복

## 11. 하프 키오스크 프린터 연결 Baseline

## 11.1 핵심 원칙

- 하프 키오스크는 **네트워크(IP) 프린터만 연결 가능**
- **USB 프린터 / 공유 프린터 연결 불가**
- 프린터 설정 방식은 **호스트 네임** 기준

## 11.2 풀 키오스크 및 하프 키오스크(삼성프린터) 드라이버 설치

### Case 1. 삼성 프린터

경로

- `[내 PC] > [시스템예약(C:)] > [프로그램] > [프린터] > SamsungUniversalPrintDriver3`

설치 절차

1. 설치 동의 후 `다음`
2. 설치 유형: `신규`
3. 연결 유형: `네트워크`
4. `예, 프린터의 네트워크를 설정합니다`
5. `소프트웨어 설치 전 IP 주소를 직접 설정합니다` 는 **미체크**
6. 주소 입력란에 **호스트 네임** 입력

호스트 네임 규칙

- `[영어이름(SEC/EPS 등)+숫자]`
- 15자리 이하

### Case 2. 삼성 외 프린터

- `프린터 속성 > 웹 서비스` 의 웹페이지 접속 후 드라이버 설치
- 설치 방식은 거의 동일
- 역시 **호스트 네임 기준** 으로 설정

## 11.3 포트 및 기본 프린터 설정

1. `제어판 > 장치 및 프린터 > 프린터 속성 > 포트`
2. `[포트 구성]` 눌러 확인
3. `[프린터 이름 또는 IP 주소]` 에 **호스트 네임** 반영 여부 확인
4. 해당 프린터를 **기본 프린터** 로 설정
5. `키오스크 HW설정 > 환경설정` 에서 `하프 키오스크` 선택
6. `키오스크 HW설정 > 프린터 설정` 에서 연결 프린터 선택

### 주의

- 포트가 `WSD` 또는 `IP` 로 잡히면 **기본값 아님**
- 이 경우 호스트 네임을 찾아 새 포트로 수동 입력 필요

## 11.4 호스트 네임 확인 방법

### Case 1. 액정 스크린 있는 프린터

- 프린터 액정에서 `보고서 출력` 또는 `리포트 출력` 후 호스트 네임 확인

### Case 2. 액정 스크린 없는 프린터

- 프린터 웹페이지 접속
- `Device Name` 확인
- 웹페이지가 없으면 프린터 업체 문의

### Case 3. 위 방법으로도 확인 불가

툴 실행 경로

- `Y:\UBcare\INSTALL\Deployment\YSR\9. 별도(개별,기타)\프린터다빈도`
- 툴명: `TPrinterPortHelper.exe`

확인 방법

- 방법 1: `프린터정보 표기` 클릭 후 네트워크 프린터의 호스트 이름 확인
- 방법 2: IP 입력 후 `MAC Address 보기` 로 호스트명 확인

## 11.5 새 포트 수동 추가

1. `프린터 속성 > 포트 > 포트 추가`
2. `Standard TCP/IP Port`
3. `새 포트`
4. 프린터 이름 또는 IP 주소 칸에 확인한 **호스트 네임** 입력

### 챗봇용 기본 판단

하프 키오스크에서 다음 증상은 우선 이 영역 확인

- 프린터가 안 잡힘
- HW설정에서 프린터 목록이 안 보임
- WSD/IP 포트로 연결됨
- 기본 프린터 미설정
- USB/공유 프린터로 억지 연결됨

## 12. 풀 키오스크 지정 프린터 Baseline (삼성 SL-M3830ND)

이 섹션은 **지정프린터 `삼성 SL-M3830ND` 를 사용하는 경우에만 해당** 한다.

## 12.1 프린터 장비 네트워크 설정

설정 위치: **지정 프린터 장비 자체**

설정값

- 네트워크 메뉴 > `TCP/IP(IPv4)`
- 프로토콜: `고정`
- 주소 종류: `IPv4 주소`
- IP 주소: `172.25.123.99`
- 서브넷마스크: `255.255.0.0` 로 표기된 이미지가 있으나, PC 설정/포트 설정 문맥상 실제 운영 기준은 아래 PC측과 함께 교차 검증 필요
- 게이트웨이: `172.25.0.0`
- 용지함 2, 3: **사용 안 함** 으로 장비 설정

> 문서상 표기 형식은 0 패딩이 포함되어 있으므로 실제 입력 시 현장 표기 방식 차이 주의.

### 대역 충돌 주의

- 병원 내 기존 네트워크가 동일 대역이면 변경 필요
- 예시: `172.25.123.xxx` 대역을 이미 쓰고 있으면 `172.25.124.99` 등으로 변경

## 12.2 PC 네트워크 설정

설정 위치: **지정 프린터 사용 키오스크 PC**

- `제어판 > 네트워크 및 공유센터 > 이더넷2 > 속성`
- `인터넷 프로토콜 버전4(TCP/IPv4)` 체크
- 수동 IP 설정
  - IP 주소: `172.25.123.100`
  - 서브넷 마스크: `255.255.255.0`

## 12.3 스풀 및 장치 설정

설정 위치: **지정 프린터 사용 키오스크 PC > 프린터 속성**

### 고급

- `스풀 기능을 사용하지 않고 인쇄` 적용

### 장치 설정

- 추가 용지함: **용지함 2, 3** 으로 설정

## 12.4 프린터 포트 및 USB 상태

- 프린터 속성에서 표준 TCP/IP 포트 `172.25.123.99` 체크 확인
- 프린터 뒤의 **USB 케이블은 제거 상태** 가 기본
  - USB 연결 시 오류 발생 가능

## 12.5 최종 상태 점검 - CheckPrinter

1. `CheckPrinter` 실행
2. 설치된 프린터 IP 선택 (`172.25.123.99`)
3. 2~3초 대기
4. 아래 조건이면 정상
   - `status [2]: OK`
   - `errMsgs[0]`
   - 카트리지 잔량 % 표시
   - Tray 상태 표시 (`empty` 또는 잔량)

### 챗봇용 기본 판단

풀 키오스크에서 처방전 프린터 이상 시 우선 확인할 것

1. `지정프린터(용지함2개)` 선택 여부
2. 프린터 포트가 `172.25.123.99` 로 체크되어 있는지
3. USB 케이블이 꽂혀 있지 않은지
4. 스풀 미사용 설정인지
5. 추가 용지함 2,3 설정이 맞는지
6. CheckPrinter 결과가 `errMsgs[0]` 인지

## 13. 음성안내 / 언어팩 Baseline

## 13.1 업데이트 허용 임시 설정

대상: 풀/하프 키오스크 공통

장애인 메뉴의 음성안내가 정상 작동하려면 일시적으로 윈도우 업데이트가 가능해야 함.

1. Windows 설정에서 업데이트 사용 가능 상태 확인
2. 작업관리자 > 시작프로그램 > `disable_update.bat` 우클릭 후 **사용 안 함**
3. 서비스 > `windows update` 시작유형을 **수동** 으로 변경

## 13.2 음성 언어 체크

1. Windows 설정에서 한국어 표시 언어 옵션 진입
2. 언어팩 미설치 시 다음 다운로드
   - `필기`
   - `음성`
3. 작업 완료 후 작업관리자 재실행
4. `disable_update.bat` 을 다시 **사용** 으로 설정

### 중요

- 이 마지막 재설정을 하지 않으면 **알림이 계속 키오스크 화면에 뜰 수 있음**

### 챗봇용 기본 판단

- 음성안내만 안 됨
- 장애인 메뉴에서 음성 언어 누락
- 업데이트 차단 스크립트 상태 문제

  - 예 / 아니오

- `OFF`: 결제 불가

## 17.4 제출용(보험) 문서 사용

- `ON`: 수납 시 환자가 제출용 보험 문서를 선택 출력 가능
- `OFF`: 해당 선택 화면 미노출

### 출력 문서 종류 선택

- 진료비 영수증
- 진료비 세부내역서
- 환자 보관용 처방전

설정 방식

- 체크: 환자 출력 가능
- 체크해제: 환자 출력 불가

### 챗봇용 기본 판단

- 미수금인데 키오스크 결제가 안 되는 이유
- 수납 후 추가 절차 안내가 누락되는지
- 국민행복카드 결제 옵션이 숨겨졌는지
- 제출용 보험문서가 안 뜨는지

## 20. 챗봇용 “기본 설정 이탈 체크리스트”

아래 항목은 장애 대응 시 가장 먼저 확인할 수 있도록 추린 **우선 확인사항 템플릿** 이다.

### 20.1 공통 1차 체크

- `키오스크 서비스 사용` 이 ON 인가
- 기기 종류가 실제 장비와 일치하는가
- VAN사가 실제 장비와 일치하는가
  - 풀 = KSNET
  - 하프 = SMARTRO
- CATID가 정확한가
- 메인화면 연결이 올바른가
- 테스트 설정이 `전체화면 / 운영` 으로 복구되어 있는가

### 20.2 결제 이슈 1차 체크

- 풀: KSNET 아이콘이 초록색인가
- 하프: VCAT 옵션값이 기본 기준과 일치하는가
- 포트 자동검색 / 워킹키수신 / 무결성체크가 정상인가
- 국민행복카드 / 미수금 결제 옵션이 병원 정책에 맞게 ON/OFF 인가

### 20.3 프린터 이슈 1차 체크

- 풀: `지정프린터(용지함2개)` 인가
- 풀: 표준 TCP/IP 포트 `172.25.123.99` 체크인가
- 풀: USB 케이블 제거 상태인가
- 풀: 스풀 미사용 설정인가
- 풀: CheckPrinter 결과 `errMsgs[0]` 인가
- 하프: 네트워크 프린터인가
- 하프: 포트가 호스트 네임인가 (`WSD`/`IP` 아님)
- 하프: 기본 프린터로 설정돼 있는가

### 20.4 접수 이슈 1차 체크

- 신규환자 접수 ON/OFF 상태가 병원 요구와 맞는가
- 진료과 선택 ON/OFF 상태가 맞는가
- 사전문진 ON 및 연결 상태가 맞는가
- 임시접수 ON 으로 인해 카운터 방문 안내가 뜨는 것은 아닌가
- 환자 메모 EMR 표기가 ON 되어 과도한 특기사항 노출이 발생하는 것은 아닌가

### 20.5 진료실 이슈 1차 체크

- 접수시간 / 점심 / 저녁 / 휴진 설정이 맞는가
- 일시정지 ON 상태가 아닌가
- 진료실 공지/사유 메시지가 남아 있지 않은가
- 해당 진료실이 메인화면과 연결돼 있는가

### 20.6 장애인 메뉴 / 음성안내 이슈

- 장애인 메뉴가 노출되어야 하는 설치 시점인지
- 음성안내 ON 인가
- 한국어 음성팩 설치돼 있는가
- `disable_update.bat` 재설정 상태가 맞는가

## 22. 챗봇 답변 로직에 반영하면 좋은 운영 원칙

### 26.1 키오스크 중복결제 및 비의도 결제 취소 프로세스

풀 키오스크 및 하프 키오스크에서 **중복결제** 또는 **환자가 의도하지 않은 결제**가 발생한 경우, 아래 절차에 따라 취소 요청을 진행합니다.

#### 1) 적용 대상
- 동일 건이 이중 승인된 경우
- 환자가 원하지 않는 결제가 승인된 경우
- 기타 카드 승인 취소가 필요한 경우

#### 2) 처리 절차
**① 승인번호 확인**  
해당 결제건의 **승인번호**를 우선 확보합니다. 승인번호는 아래 경로 중 하나에서 확인할 수 있습니다.

- **키오스크 플레이어** 내 과거 결제내역 조회
- **VAN 결제내역 조회 사이트** 접속 후 승인내역 조회

**② 운영기획팀 전달**  
확인한 **승인번호**를 **운영기획팀 오창훈 매니저**에게 전달합니다.

**③ VAN사 취소 요청 진행**  
운영기획팀에서 전달받은 승인번호를 기준으로 **VAN사에 취소 요청**을 진행합니다.

#### 3) VAN 결제내역 조회 사이트
| VAN사 | 서비스명 | 홈페이지 | ID | PW |
|---|---|---|---|---|
| KSNET | KSTA | https://kstaplus.ksnet.co.kr/ | UBKIOSK | a123123123 |
| KSNET | 마이장부 | https://myjangbu.ksnet.co.kr/ | UBCARE0000 | a123123123 |
| Smartro | 스마일비즈 | https://www.smilebiz.co.kr/ | ubkiosk | smartro1!2@3# |

#### 4) 운영 유의사항
- 취소 요청 전 **반드시 해당 결제건의 승인번호를 먼저 확인**해야 합니다.
- 병원명, 결제금액, 결제시각만으로는 취소 요청 처리에 한계가 있으므로, **승인번호 확보가 우선**입니다.
- **중복결제**와 **비의도 결제**는 동일한 프로세스로 처리합니다.
- 승인번호 확인이 어려운 경우에는 우선 **키오스크 플레이어 결제내역 조회 → VAN 사이트 조회** 순으로 확인합니다.

### 26.2 키오스크 계약건 납품일정 변경/조정 프로세스

키오스크 계약건의 납품일정 변경 또는 조정이 필요한 경우, 아래 절차에 따라 요청합니다.

#### 1) 적용 대상
- 병원 요청에 따른 납품일 변경
- 설치 일정 재조정 필요 건
- 시간대 변경 또는 납품 순서 조정 필요 건

#### 2) 처리 절차
**① 변경 요청 정보 정리**  
아래 정보를 정리합니다.

- **납품예정 병원명**
- **변경 희망 날짜**
- **변경 희망 시간**

**② 운영기획팀 사전 전달**  
정리한 내용을 **운영기획팀 오창훈 매니저**에게 **이메일, 문자 등**으로 우선 전달합니다.

**③ 유통사 협의 후 일정 확정**  
운영기획팀에서 유통사와 협의한 뒤, 최종 납품일정을 확정합니다.

#### 3) 운영 유의사항
